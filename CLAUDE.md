# Семейный бюджет

PWA для учёта семейных трат с синхронизацией между телефонами. Пользуется только семья.
Общаемся по-русски, интерфейс и комментарии в коде — тоже на русском.

- Сайт: https://joker1796.github.io/family-budget/ (GitHub Pages, репозиторий Joker1796/family-budget — публичный)
- Бэкенд: Google-таблица + Apps Script (`apps-script/Code.gs`), развёрнут как веб-приложение с доступом «Все»; защищён семейным паролем из Script Properties `FAMILY_SECRET`
- Валюта — рубли

## Стек и команды

Vue 3 (`<script setup>`), Vite, vite-plugin-pwa, иконки lucide-vue-next. Без роутера и без библиотек состояния.

```
npm run dev     # фронт на :5173 (с --host, можно открыть с телефона в той же сети)
npm run mock    # локальный бэкенд на :18787, пароль test — запускает настоящий Code.gs в node:vm с эмуляцией SpreadsheetApp
                # данные мока только в памяти; с телефона адрес бэкенда — http://<IP мака>:18787, не localhost
npm run build
npm run icons   # PNG-иконки из public/logo.svg
```

Деплой: пуш в `main` → `.github/workflows/deploy.yml` собирает с `BASE_PATH=/<repo>/` и публикует на Pages.
Изменения `Code.gs` на GitHub не попадают в Google автоматически: код нужно вставить в редактор Apps Script и сделать
«Управление развёртываниями → Изменить → Новая версия» (URL при этом не меняется).
Делает это пользователь сам. Давать ему пошаговую инструкцию со ссылками: https://script.google.com/home (или таблица →
Расширения → Apps Script); код — `pbcopy < apps-script/Code.gs` или https://raw.githubusercontent.com/Joker1796/family-budget/main/apps-script/Code.gs.
Предупреждать: не «Новое развёртывание» — у него другой URL, придётся перенастраивать телефоны.

«Подними стенд» = `npm run mock` + `npm run dev -- --port 5173 --strictPort` в фоне; сообщить адреса для мака и для телефона (`ipconfig getifaddr en0`).

## Устройство

- `src/store.js` — всё состояние: записи в localStorage, очередь неотправленных изменений, `sync()`.
- `src/api.js` — один POST на Apps Script телом `text/plain` (иначе браузер сделает CORS preflight, которого Apps Script не умеет).
- `src/savings.js` — копилки: остатки счетов считаются проигрыванием истории операций.
- `src/local.js` — `localRef()`: то, что помнит конкретный телефон (последняя вкладка Итогов и тип на экране добавления).
- `src/recurring.js` — регулярные платежи: когда платёж положен, статус, прогноз (фикс. сумма или медиана последних 6 оплат), напоминания.
- `src/icons.js` — доступные иконки категорий (ключ хранится в таблице, в колонке `icon`).
- `src/App.vue` — вкладки: История (траты и доходы), Платежи, «+» Добавить (по центру), Итоги, Копилки. Настройки — шестерёнка в шапке.
- `src/components/` — экраны и свои контролы: `Segmented`, `Select`, `DateField` (календарь), `Dropdown` (общая оболочка),
  `AmountInput` (поле суммы с разрядами), `Donut` (кольцевая диаграмма).
- `src/theme.js` — выбор темы (тёмная/светлая) на конкретном телефоне.
- Итоги (`StatsView`): переключатель Расходы/Доходы; расходы — полосами, доходы — кольцом (≤ 6 сегментов, хвост → «Остальное»).

### Синхронизация

- Сущности: `tx` (траты/доходы), `rec` (регулярные платежи), `cat` (категории), `acc` (счета копилок), `sav` (операции по ним)
  → листы Transactions, Recurring, Categories, Accounts, Savings.
- Клиент шлёт `{ secret, action: 'sync', ops: [{tx}|{rec}|{cat}|{acc}|{sav}], since }`, сервер применяет и возвращает всё с `updatedAt > since` и `serverTime`.
- `updatedAt` проставляет сервер, строго больше текущего максимума; побеждает последняя запись. Удаление — флаг `deleted`, строки не стираются.
- Пока id есть в локальной очереди, серверная копия его не перезаписывает.
- Колонки читаются по заголовкам; новые колонки добавлять в конец `TABLES` — `ensureSheet()` сам допишет их в существующую таблицу.
- Если в ответе сервера нет ключа сущности (старый Code.gs), её op'ы остаются в очереди, а в шапке — ошибка «обновите развёртывание».
- Поменялся формат локальных данных → увеличить `SCHEMA` в store.js: кэш записей сбросится и перекачается с сервера (очередь сохраняется).

### Важные решения

- Траты ссылаются на категорию **по названию**; переименование категории каскадом переименовывает траты и платежи.
- Кто внёс запись, не учитываем (семья вносит траты вдвоём с двух телефонов). Колонка `author` в таблице осталась, но пустая.
- Оплата регулярного платежа — обычная трата с `recurringId` и `period` (YYYY-MM).
- Копилки с тратами и доходами не связаны — только следить за остатками на вкладах. Операция: `in` пополнение, `out` снятие,
  `set` «уточнили остаток» (amount = новый остаток, например после процентов). История ссылается на счёт по id.
- Счёт может быть заблокирован: `locked` + `lockedUntil` (YYYY-MM-DD, пусто — бессрочно); в день `lockedUntil` уже свободен (`isLocked()` в savings.js).
  Если старый Code.gs вернул счёт без `locked` — op остаётся в очереди (`NEW_FIELDS` в store.js); новые колонки — туда же.
- История (вкладка трат) фильтруется по категории (`Select` под месяцем); фильтр живёт до перезапуска приложения.
- Экран добавления: категорию и сумму можно выбирать в любом порядке, сохранение только кнопкой (или Enter), после — «Отменить».

## Дизайн

- Основная тема тёмная, акцент — морская волна (`--accent #2b7f7a`, `--accent-text #6cc3ba`), палитра в `:root` в `src/style.css`.
  Есть светлая кремово-розовая (`:root[data-theme='light']`) — выбирается в Настройках, хранится на телефоне (`fb.theme`, `src/theme.js`), не синхронизируется.
  Цвета только через переменные (`--on-accent`, `--selected`, `--placeholder`, `--shadow` и т.д.), без захардкоженных `#fff`.
- Никаких скруглений (`border-radius: 0` везде).
- Никаких системных выпадашек: только свои `Select` / `DateField`. Суммы — через `AmountInput` (разряды пробелами по мере ввода). Поля ввода — 16px (иначе iOS зумит).
- Всё, что движется, — плавно: переменные `--ease`, `--fast`, `--normal`; классы переходов `slide-left/right`, `fade`, `pop`, `expand`, `list`, `drop`. Учитывается `prefers-reduced-motion`.

## Правила

- `docs/` (Excel с реальными тратами за 2023–2025) — в `.gitignore`, в публичный репозиторий не выкладывать. Как и пароль/URL скрипта.
- Порты 5174/5175 заняты другими проектами — не трогать.
- Анимации проверять в headless Chrome (playwright-core), а не во вкладке Claude-in-Chrome: она в фоне, и переходы там замирают.
  playwright-core в проекте не установлен — ставить во временную папку и запускать с
  `executablePath: '/Applications/Google Chrome.app/Contents/MacOS/Google Chrome'`.
- Цвета диаграмм — переменные `--series-1…6` / `--series-other`, своя ступень для каждой темы. Порядок фиксирован;
  менять только с проверкой палитры на различимость (в т.ч. при дальтонизме) — валидатором из скилла dataviz.
